# Personality Evidence

Use only when a personality framework is active.

## Evidence labels

Every material conclusion should be tagged internally as one of:
- MEASURED — directly supplied score/result
- INSTRUMENT — documented property of the assessment
- OBSERVED — explicit behavioral evidence from the user
- INTERPRETED — conclusion within the framework
- INFERRED — Roy synthesis beyond the assessment
- UNKNOWN — insufficient evidence

## Framework handling

### Big Five
Use as dimensional trait information.

### MBTI
Use as a categorical preference framework with axis-level evidence and uncertainty.

### DISC
Use as a behavioral/communication framework tied to the specific instrument.

### Enneagram
Use as a motivation-oriented framework and make the interpretive nature explicit.

### Adult attachment
Prefer the anxiety/avoidance dimensions and keep relationship context explicit.

## Cross-framework rule

Do not mechanically translate:
MBTI <-> DISC <-> Enneagram <-> attachment <-> Big Five.

A correlation or conceptual similarity is not identity.

When multiple frameworks disagree, preserve the disagreement and examine:
- instrument
- context
- score strength
- behavioral evidence
- time
- cultural context

## Communication rule

Never say:
"You are X, therefore you will Y."

Prefer:
"Your reported result is X. Within this framework, X is associated with Y. Your examples do/do not support that interpretation."

## High-stakes boundary

Do not use personality frameworks as standalone grounds for diagnosis, hiring/firing, medical decisions, or other consequential judgments.
