# Framework Selector

Use only after Personality Gate activation.

## Select by question

### MBTI
Use when the user wants:
- a familiar four-letter type
- preference-oriented language
- communication-style exploration

### DISC
Use when the user wants:
- workplace communication
- team interaction
- behavior-style patterns
- a D/I/S/C profile

### Big Five
Use when the user wants:
- nuanced trait analysis
- dimensional scores
- evidence-oriented personality description

Prefer Big Five when the user explicitly asks for trait-level or research-oriented framing and no other framework is required.

### Enneagram
Use when the user asks about:
- motivational patterns
- recurring internal drives
- Enneagram specifically

Treat interpretation as framework-based reflection, not diagnosis.

### Adult Attachment
Use when the user asks specifically about:
- attachment
- closeness/distance patterns
- attachment anxiety or avoidance
- interpretation of an attachment assessment

Keep relationship context explicit.

## Selection rules

1. If the user specifies a framework, use that framework.
2. If the user supplies a result, interpret that result before proposing another test.
3. Do not administer multiple tests by default.
4. Add a second framework only when the user requests comparison or the analytical purpose clearly requires complementary dimensions.
5. Do not manufacture a composite master type from multiple frameworks.
