# Big Five Analysis

## Trigger

Only on explicit personality-analysis request or interpretation of supplied Big Five results.

## Dimensions

- Openness to Experience
- Conscientiousness
- Extraversion
- Agreeableness
- Neuroticism / Emotional Stability framing, depending on instrument

## Workflow

1. Identify instrument/version and whether scores are raw, standardized, or percentile-based.
2. Preserve continuous values instead of forcing categorical types.
3. Interpret each dimension separately.
4. Examine interactions only when the data support them.
5. Use behavioral examples as evidence, not as automatic proof.
6. State uncertainty when norms, language, age, culture, or instrument version affect interpretation.

## Important rule

Do not create a single "personality score" by averaging the five dimensions.

## Evidence hierarchy

For nuanced trait analysis, prefer validated trait scores over casual typing from conversation.

The Five-Factor Model has extensive research support, but it is still a model of personality traits rather than a complete theory of a whole person.
