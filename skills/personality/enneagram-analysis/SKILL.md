# Enneagram Analysis

## Trigger

Only on explicit request for Enneagram/personality analysis.

## Workflow

1. Identify the exact assessment or source version.
2. Preserve the result and any wing/subscore information.
3. Separate observed motivations from the framework's interpretation of those motivations.
4. Ask for concrete examples when the result is ambiguous.
5. Treat type descriptions as hypotheses for reflection, not as objective psychological diagnoses.

## Do not infer

Do not assign an Enneagram type from a few messages or from a user's MBTI/DISC result.

Do not present type as immutable, morally loaded, or causally exhaustive.

## Test handling

Retrieve the exact instrument/source at execution time. Do not embed a large proprietary or third-party item bank in the skill.
