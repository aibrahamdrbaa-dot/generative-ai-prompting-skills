# MBTI Analysis

## Scope

Use for an explicit MBTI request or interpretation of a supplied MBTI assessment.

## Workflow

1. Identify the exact assessment/version when known.
2. Preserve the four-letter result separately from the evidence for each axis.
3. Inspect axis strength or borderline status when scores are available.
4. Compare the result with concrete user examples only as supporting or contradicting evidence.
5. Explain the result within MBTI's preference/type framework.
6. State what the result cannot establish.

## Do not infer

Do not infer an MBTI type from ordinary conversation.

Do not convert type into intelligence, moral character, competence, mental health, or destiny.

## Test handling

If a test is requested, use Assessment Adapter to identify and score the exact instrument. Do not embed an unofficial question bank into this skill.

## Output

Result -> Evidence -> Interpretation -> Limits
