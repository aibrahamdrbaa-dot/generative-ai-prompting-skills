# Enneagram Analysis

## Workflow

1. Identify the exact assessment/source version.
2. Preserve type, wing, and subscores when available.
3. Separate user-described motives from the framework's interpretation of those motives.
4. Ask for concrete examples when the result is ambiguous.
5. Treat type descriptions as hypotheses for reflection.

## Do not infer

Do not assign an Enneagram type from a few chat messages or from MBTI, DISC, or Big Five results.

Do not present type as immutable, morally loaded, or causally exhaustive.

## Test handling

Use Assessment Adapter for source selection and scoring.
