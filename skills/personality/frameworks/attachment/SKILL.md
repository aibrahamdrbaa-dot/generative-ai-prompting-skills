# Adult Attachment Analysis

## Core representation

Prefer continuous dimensions:
- attachment anxiety
- attachment avoidance

Use categorical labels only when the instrument or user specifically requests them.

## Workflow

1. Identify instrument/version.
2. Preserve raw dimension scores.
3. Keep the relationship context explicit.
4. Distinguish romantic-partner data from family/friendship data.
5. Interpret scores as relationship-pattern information, not diagnosis.
6. Do not infer trauma or psychiatric disorder from attachment scores.
7. State relevant population and cultural limits.

## Test handling

Use Assessment Adapter for exact instrument administration and scoring.
