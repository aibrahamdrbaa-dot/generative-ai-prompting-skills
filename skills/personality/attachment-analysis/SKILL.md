# Adult Attachment Analysis

## Trigger

Only on explicit request about attachment style or interpretation of an attachment assessment.

## Core representation

Prefer continuous attachment-related dimensions such as:
- attachment anxiety
- attachment avoidance

Use categorical labels only when the instrument or user specifically asks for them.

## Workflow

1. Identify instrument/version.
2. Preserve raw dimension scores when available.
3. Interpret in the relationship context specified by the user.
4. Separate romantic-partner context from friendship/family context.
5. Avoid diagnosing disorders or inferring hidden trauma from an attachment score.
6. Mention cultural/contextual limits when relevant.

The ECR-R has published evidence for reliability and validity, but interpretation still depends on the population and context studied. See the source register.
