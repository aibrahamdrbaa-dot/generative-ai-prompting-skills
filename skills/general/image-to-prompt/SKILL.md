# Image to Prompt
Recover: subject; composition; viewpoint; lighting; color; materials; depth; typography; medium; post-processing.
Do not invent hidden metadata, identities, lens values, software or locations.
Extract 3–5 critical visual anchors first.
For editing, explicitly separate what changes from what must remain unchanged.
Output a reusable template and a concrete prompt.
