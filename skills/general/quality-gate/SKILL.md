# Quality Gate

Aesthetic quality alone is not enough.

## Gate A — Task compliance
- correct modality
- correct operation
- requested subject/action present
- correct count
- correct framing/aspect where specified

## Gate B — Constraint compliance
- invariants preserved
- no accidental objects or text
- references used according to assigned roles
- no unsupported facts visually invented when factual accuracy matters

## Gate C — Technical
- requested resolution/aspect/settings actually applied
- text legible and exact
- image/video continuity acceptable
- audio matches requested layers

## Gate D — Presentation
- style coherent
- lighting coherent
- materials plausible
- composition usable for the intended medium

## Gate E — Learning
Record only durable lessons:
- route
- failure
- correction
- confidence
- source/version

Do not turn a one-off artifact preference into a permanent rule.
