# Typography & Layout
Treat the task as a layout problem.
Specify canvas/orientation, hierarchy, exact literal copy, placement, relative scale, spacing and image region.
Put required text in quotation marks.
Enumerate repeated labels and counts.
Do not ask the model to invent factual statistics or hidden copy.
