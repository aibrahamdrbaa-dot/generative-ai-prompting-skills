# Prompt Curator
## Score 100
25 official alignment; 20 model specificity; 15 recency; 20 demonstrated output/evidence; 10 workflow/reusability; 10 provenance/licensing.
## Prefer
Official guidance, maintained skills, tested examples, curated libraries with visible outputs.
## Reject/quarantine
Unclear provenance, stale model IDs, generic adjective dumps, contradictory API advice, hidden assets, unclear redistribution rights.
## Rule
Use third-party prompts to learn patterns. Write original prompts for the user unless redistribution rights are clear.
## Evidence labels
OFFICIAL, MAINTAINED, CURATED, COMMUNITY, INFERRED.
