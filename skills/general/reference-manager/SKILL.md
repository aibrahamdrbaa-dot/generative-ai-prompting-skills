# Reference Manager

Never treat a set of references as an undifferentiated pile.

## Reference roles

Use one or more:
- subject identity
- product geometry
- architecture
- pose
- wardrobe
- composition
- environment
- style
- color
- typography/layout
- motion reference

## Conflict resolution

For every important property:
1. identify its controlling reference
2. identify which references are supportive
3. identify which references must not override it

Example:
- Reference 1 controls face identity.
- Reference 2 controls room architecture.
- Reference 3 controls lighting/style.

## Preservation

For an edit, state:
change X; keep Y, Z and framing unchanged.

For a generation using references, do not invent attributes absent from the references unless the user explicitly asks for them.
