# Prompt Architect
Build from finished artifact → subject → composition → environment → visual mechanisms → references → constraints.
Add detail only when it changes structure, identity, spatial relationships, lighting, materials, typography or motion.
Translate vague adjectives into observable causes.
Keep settings (size, ratio, quality) separate from prompt prose.
Check contradictions and omissions before handoff.
