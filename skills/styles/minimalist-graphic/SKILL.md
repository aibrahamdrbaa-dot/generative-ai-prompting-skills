# Minimalist Graphic
Control grid, whitespace, hierarchy, alignment, limited palette, typography scale and one focal visual.
Remove decorative elements that do not support the hierarchy.
Use exact text and define where it belongs.
Do not confuse minimalism with emptiness; every remaining element should have a job.
