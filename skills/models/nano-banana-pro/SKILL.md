# Nano Banana Pro

## Provider identity
Official model ID: `gemini-3-pro-image`.

## Use it for
- complex visual tasks;
- professional design;
- high-fidelity product mockups;
- factual data visualization;
- advanced localization;
- brand-sensitive assets;
- dense multi-constraint briefs.

## Prompt anatomy
Professional artifact + purpose → primary subject → reference authorities → composition → environment → materials/color → lighting → typography/data → preserve/change → exclusions.

## Reference authority
Give every reference a job and resolve conflicts explicitly. Protect identity anchors such as product silhouette, architecture, label placement and proportions.

## Grounding/localization
Separate factual content from visual interpretation. When factual or geographic correctness matters, use supported Search Grounding and verify the facts before visual generation.

## Brand work
Preserve supplied brand assets where required. Do not invent extra logos, labels or signage.

## Complex layouts
Describe hierarchy, grid, alignment, spacing and exact copy. Verify text and factual relationships in the output.
