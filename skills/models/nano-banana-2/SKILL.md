# Nano Banana 2
Model: `gemini-3.1-flash-image`.
## Best use
General-purpose image generation/editing, multi-reference work, consistency, text rendering and fast iteration.
## Prompt anatomy
Artifact/purpose → subject → composition → reference roles → visual treatment → lighting/materials → text/layout → preserve/change → exclusions.
## References
Assign each image a role such as architecture, product, pose, identity, style or environment.
## Editing
Use targeted transformations and preserve established geometry and composition.
## Grounding
For current real-world facts, use supported search grounding rather than inventing them.
## Output settings
Resolution and aspect ratio belong in settings, not filler words.
