# General Prompt Patterns
These are original synthesis examples.

## Product
```
Create a clean commercial product photograph of a matte ceramic bottle on a pale limestone pedestal. Keep the bottle centered slightly left and leave generous negative space on the right for later copy. Use soft directional studio daylight, subtle contact shadow, realistic ceramic grain and restrained warm neutral colors. No people, no extra products, no invented logo, no text.
```

## Reference edit
```
Use the supplied room photo as the structural authority. Change only the furniture style to contemporary warm-minimal pieces. Keep wall geometry, window positions, floor boundaries, perspective and lighting direction unchanged. Do not add rooms, windows, decor or people.
```

## Poster
```
Create a portrait editorial poster with the exact headline "AI FOR EVERYDAY WORK" in the upper third and the exact line "A PRACTICAL WORKSHOP" near the bottom. One photographic hero occupies the center. Keep strong hierarchy, generous whitespace, crisp alignment and no additional text.
```
