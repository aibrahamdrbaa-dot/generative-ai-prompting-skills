# Model Capability Matrix — 2026-09-23

This matrix is a routing aid, not an overall ranking. Provider documentation is authoritative when it changes.

| Model | Primary modality | Strong routing signals | Main role in this system |
|---|---|---|---|
| Gemini Omni 1.1 Flash | Video in/out | text-to-video, image-to-video, reference-guided video, conversational edits, extension, first/last-frame transitions | Video engine |
| Nano Banana 2 / Gemini 3.1 Flash Image | Image | general generation/editing, multiple references, consistency, fast iteration, 4K-capable image work | Image workhorse |
| Nano Banana Pro / Gemini 3 Pro Image | Image | complex briefs, professional assets, grounding/localization, dense constraints, brand-sensitive layouts | Complex image engine |
| GPT Image 2.5 Flare | Image | latency-sensitive GPT Image 2.5 workflows | Fast OpenAI image route |
| GPT Image 2.5 Sunburst | Image | detail/quality-sensitive GPT Image 2.5 workflows | Quality-oriented OpenAI image route |

## Routing principles

1. Omni is selected because the request is video-native, not because it is globally better.
2. Nano Banana 2 is the general image route when speed and capability breadth matter.
3. Nano Banana Pro is the precision/complexity route.
4. GPT Image 2.5 is selected when its workflow, editing behavior, or user context makes it appropriate.
5. A model route never replaces a domain, reference, typography, continuity, or QA skill.
