## Recommended stacking

- Generic image brief → Prompt Architect + target model skill.
- Reference image recreation → Image to Prompt + target model skill.
- Precise edit → Visual Editing + target model skill.
- Poster/infographic/UI-like image → Typography & Layout + target model skill.
- Real estate → Real Estate Visuals + target model skill.
- Researching existing examples → Prompt Curator + target model skill.

## Curation philosophy

The package is intentionally smaller than large prompt dumps. It keeps reusable techniques, model-aware rules and original examples, while linking to third-party libraries for research.
