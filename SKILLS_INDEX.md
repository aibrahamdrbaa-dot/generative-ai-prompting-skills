## Combination rules

1. Always start with the target model skill when a model is known.
2. Add a general skill only when its trigger applies.
3. Add one or more style skills when the visual language is important.
4. Add a specialty skill when the domain changes what "correct" means.
5. Use Prompt Curator when researching examples, not as a substitute for model documentation.
